# Wait a second, please — документация проекта

Мобильная игра (Unity 6000.3.10f1, URP, Input System, Android и iOS). Чёрно-белый нуар в духе «Города грехов» с акцентами: жёлтый — то, что летит в тебя, красный — то, что убивает. Игрок сам бежит вперёд по улице (как в Pistol Whip) и уворачивается от пуль гангстеров наклоном телефона. Время замедляется от опасности, и пуля медленно проходит у уха, как в «Матрице» и Superhot. При близком промахе (close) игрок сам стреляет в ответ.

Этот файл — точка входа. Здесь содержание, карта кода и правила. Подробности по каждой теме — в отдельных файлах ниже. Читай их вместо того, чтобы каждый раз заново разбирать код.

## Как пользоваться

- **Найти:** открой тему по таблице, затем раздел «Как устроено» — там файлы, поток и ключевые настройки.
- **Обновлять:** любая реализованная правка, новая настройка или решение пользователя попадает в файл своей темы **в том же коммите**, что и код. Решения записывай с датой. Отклонённое переноси в «Отклонено», чтобы не предлагать его снова.
- **Кто правит:** файл темы обновляет сессия-владелец. Этот индекс (таблицы, «Состояние», «Карта кода») — тот, кто добавил или удалил файл, скрипт или тему.
- **Если документ расходится с кодом,** прав код. Исправь документ и отметь это в коммите.

## Карта кода

Все скрипты лежат в `Assets/Scripts`.

| Скрипт | Тема | Что делает |
|---|---|---|
| `TiltInput` | время и управление | наклон с датчика (в редакторе — мышь), углы и скорость наклона, калибровка |
| `TimeScaleController` | время и управление | режимы TILT и DANGER, удержание замедления/обычного времени, `Flow`, события входа/выхода из слоу-мо |
| `PlayerTiltDodge` | время и управление | сдвиг и наклон камеры от угла телефона |
| `CameraMovement` | время и управление | бег вперёд в игровом времени |
| `ControlOptions` | время и управление | переключатели (PlayerPrefs) |
| `ControlsPanel` | время и управление | меню CONTROLS (IMGUI), подгонка камеры для книжной ориентации |
| `Projectile` | выстрел | пуля врага: встреча с глазами, правило уворота и close, API для DANGER, `PassedPlayer`/`HitPlayer` |
| `ProjectileSpawner` | выстрел | ствол врага: пускает пулю из пула |
| `ShotEffects` | выстрел | кольца в воздухе, красный блик прицела, жёлтая вспышка, экран смерти со стрелком |
| `AirRingTrail` | выстрел | запись колец за летящей пулей |
| `CounterShot` | выстрел | ответный выстрел при close и пуля игрока, удержание слоу-мо |
| `PlayerGun` | выстрел | пистолет игрока внизу справа |
| `JaggedHole` | выстрел | рваная красная виньетка экрана смерти |
| `GameSession` | выстрел + надписи | счёт, смерть, рестарт, HUD (общий файл) |
| `EnemyGunman` | враги | поведение врага: укрытие, выход, прицел, выстрел; API для выстрела и времени |
| `EnemyBody` | враги | ноги: присед, приставной шаг, IK |
| `EnemyDeath` | враги | смерть: отброс, кровь, шляпа |
| `BloodStain` | враги | пятно крови на стене или дороге |
| `EnemySpawner` | враги | расстановка по меткам, рост сложности по дистанции, `DistanceRun` |
| `EnemySpot` | враги + окружение | метка для врага, тип укрытия |
| `CityStreetSpawner` | окружение | бесконечная улица из сегментов, укрытия, метки, слой `StreetCover` |
| `NoirRain` | окружение | дождь на камере, в игровом времени |
| `NoirPostEffects` | окружение | постобработка (контраст, зерно, виньетка) |
| `PrefabPool` | общее | пул объектов |
| `FloorSpawner`, `ReturnToPoolBehindPlayer` | старое | первый прототип (`SampleScene`) |

**Шейдеры (`Assets/Shaders`):** `NoirCity`, `NoirLightPool` — окружение; `NoirEnemy` — враги; `ShotRings`, `ShotInk`, `ShotSolid`, `ShotSpotlight` — выстрел.

**Ресурсы, которые код грузит по имени,** лежат в `Assets/Resources`: материалы `Shot*`, префабы `PlayerBullet` и `PlayerGun`. Остальные материалы (в том числе `Yellow.mat` пули и `PlayerGun.mat`) — в `Assets/Materials`.

## Правила работы

Подробно — в [tooling.md](tooling.md).

1. **Сначала обсуждение.** Без явной команды пользователя («реализуй» или равнозначной) на конкретную правку ничего не менять ни в проекте, ни в Unity. Переслать идею другой сессии — не значит дать ей команду.
2. **Каждая правка — у владельца темы.** Просьбу по чужой теме пересылай владельцу с дословными словами пользователя. Если тема ничья — предложи новую сессию.
3. **Коммиты** делает каждая сессия только со своими файлами, по очереди. Пушит основная сессия. Документ темы обновляется в том же коммите.
