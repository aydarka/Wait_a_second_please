# Инструменты и порядок работы

**Владелец:** основная сессия.

## Unity и проект

- **Unity:** 6000.3.10f1 (Unity 6.3 LTS), URP (`PC_RPAsset` / `Mobile_RPAsset`), Input System 1.18 (старый Input Manager выключен), uGUI 2.0.
- **Платформа редактора:** Android. Она же нужна для Unity Remote. Модуль Android Build Support со встроенными SDK/NDK/JDK установлен.
- **Цели:** большинство Android-телефонов и iPhone. Тестовые устройства: Redmi Note 9 (слабый Android), iPhone 14 Pro, Mac для сборок под iOS.
- **Сборка:** первая сцена — NoirStreet. Сборки APK и iOS ещё не делались, у темы пока нет владельца.

## Unity MCP (управление редактором из Claude)

- **Пакет:** `com.coplaydev.unity-mcp` `#v10.0.0` в `Packages/manifest.json`.
- **Сервер:** `mcp-for-unity` v10.0.0, установлен через `uv tool`. Подключён в `.mcp.json` как `UnityMCP` с `--default-instance Wait_a_second_please`. Версии пакета и сервера должны совпадать.
- **Ловушки:**
  - **Перезагрузка домена.** Пока редактор перезагружает домен (компиляция, вход в Play), сервер молча шлёт команды в другой открытый редактор (Alkahest и др.). После каждой перезагрузки проверь `mcpforunity://instances` и заново вызови `set_active_instance` с `Wait_a_second_please@731eaaaa`. В `execute_code` проверяй `Application.productName`.
  - **Фокус.** Без фокуса окна Unity Play Mode не тикает и зависает на входе. Гонять кадры: `EditorApplication.isPaused = true; EditorApplication.Step();` (каждый `Step` — кадр с unscaledDeltaTime 0,02).
  - **`execute_code`** компилируется как C# 6: без интерполяции строк, `UnityEngine.Object.Find...`.
  - **Ввод в тестах:** имитация через `InputState.Change(Mouse.current, MouseState)`. Нажатие кнопки — через `MouseState.WithButton`; `InputState.Change` на сам `leftButton` не работает.
  - **Скриншоты** — в `Temp/Screenshots`.
  - **Ожидание перезагрузки:** фоновый цикл по `netstat` до появления порта 6400 (foreground `sleep` запрещён).

## Unity Remote 5 (тест на телефоне без сборки)

- **Работает только при активной платформе Android.** На Windows-платформе Unity не делает `adb forward tcp:7201 tcp:7201`, и картинки нет; обход — проброс вручную встроенным adb.
- **adb:** встроенный, `C:\Program Files\Unity\Hub\Editor\6000.3.10f1\Editor\Data\PlaybackEngines\AndroidPlayer\SDK\platform-tools\adb.exe`. В EditorPrefs `AndroidSdkRoot` указывает на несуществующий `C:/Android/SDK` — Unity всё равно берёт встроенный.
- **Порядок:** открыть Remote на телефоне → в Unity нажать Play → не уходить из окна Unity.
- **Ввод:** через Remote приходят Touchscreen и включённый акселерометр; гравитация и гироскоп — позже и выключенными (`TiltInput` это учитывает).
- **Звук через Remote на телефон не идёт.**
- `%LOCALAPPDATA%\Unity\Editor\Editor.log` может содержать вывод других редакторов — сначала смотри заголовок.

## Serena

C#-навигация (найти символ, ссылки, обзор файла) — сервер `serena` в `.mcp.json`, конфиг `.serena/project.yml`. Дашборд и окно логов выключены: на Windows они плодят процессы WebView2 на десятки ГБ.

## Git

- **Ветка прототипа:** `prototype/tilt-time-noir` (на GitHub). `main` не трогаем без просьбы.
- **Коммиты:** каждая сессия — только свои файлы, по очереди. Если файлы сессий друг без друга не собираются — одним коммитом.
- **Пуш** делает основная сессия, после проверки: консоль Unity чистая, рабочая копия совпадает с HEAD.
- **Документ темы** в `Docs/` обновляется в том же коммите, что и код.
- В конце сообщения коммита — строка `Co-Authored-By`.
